# Milaserv-UPC

منصة تشغيل موحدة لخدمة العملاء والعمليات — React (RTL, عربي/إنجليزي).

## الهيكل الرئيسي للـ Sidebar

التنقل الرئيسي معرَّف في `Dashboard.jsx` داخل `SIDEBAR_SECTIONS` (Data-driven: إضافة قسم أو صفحة = إضافة سطر في الـ config بدون تعديل مكونات الواجهة).

| # | القسم | Section | الوصف |
|---|-------|---------|-------|
| 1 | خدمة العملاء | Customer Care | تشغيل خدمة العملاء اليومي: المكالمات، التذاكر، الشكاوى، CSAT، لوحة الوردية |
| 2 | إدارة العملاء | CRM | الـ Leads والمبيعات: الرفع والتوزيع والمتابعات وطلبات التيلي سيلز |
| 3 | قاعدة المعرفة | Knowledge Base | مرجع موحد: مقالات، سياسات، نصوص مكالمات، إرشادات التأمين ووصفتي |
| 4 | مركز الفروع | Branches Center | بيانات الفروع، ساعات العمل، التذاكر والتصعيدات، المستندات |
| 5 | United Pharmacy DIC | Drug Information Center | البيانات الدوائية: قاعدة الأدوية، البدائل، التصنيف (عادي/خاص/رقيب)، التغطيات |
| 6 | التوصيل واللوجستيات | Delivery & Logistics | طلبات التوصيل وحالاتها، الفترات، المدن والأحياء، أداء المناديب |
| 7 | التقارير | Reporting | التقارير التشغيلية والإدارية + منشئ تقارير مخصص وتصدير Excel/PDF |
| 8 | الأداء ومؤشرات القياس | Performance & KPIs | مؤشرات الموظف والفريق، الأهداف، AHT، SLA، الترتيب ونسب الإنجاز |
| 9 | الطلبات الإدارية | HR Request | طلبات الموظفين الداخلية ومسار الموافقات |
| 10 | إدارة الفرق | Team Management | الفرق والموظفون والأدوار، جدولة الورديات، إسناد المهام والفروع والشركاء |
| 11 | الإعدادات | Settings | مقسمة داخلياً: عامة، شركاء، اتصالات، تشغيلية، أمان، تكامل |

- العناصر المؤجلة (مثل Branch Stock Integration وWhatsApp) معلَّمة بـ `soon: true` وتظهر بشارة «قريباً».
- الـ Sidebar يدعم البحث في القائمة (عربي/إنجليزي)، الطي والفتح لكل قسم، ومستويات تداخل متعددة (مثل حالة التوصيل وإعدادات الأمان).
- الصفحات غير المبنية بعد تعرض Placeholder موحّد مع الـ Breadcrumb الكامل.

## الفرق الرئيسية (Master Teams)

مثبتة في `TEAMS` داخل `Dashboard.jsx` — إضافة أي فريق جديد تتم بإضافة سطر واحد بدون تعديل الكود:

1. Customer Care Team — فريق خدمة العملاء
2. Online Operation Team — فريق العمليات الأونلاين
3. Telesales Team — فريق التيلي سيلز
4. OST — فريق OST
5. Business Excellence — تميز الأعمال
6. Marketing Team — فريق التسويق
