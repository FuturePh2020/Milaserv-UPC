# ثيم Bazaar Pop لـ EasyOrders — دليل التركيب والإعداد

ثيم مخصص (Custom Theme) كامل لمنصة EasyOrders، عربي RTL افتراضياً، للسوق المصري، بطابع "ريتيل مرسوم" ملوّن: حدود غامقة، ظلال صلبة، ستيكرز، نجوم، حواف متموجة، وكولاج منتجات.

> **الحالة:** متنفّذ ومختبَر محلياً فقط (LiquidJS + متصفح). **لم يُختبر بعد داخل متجر EasyOrders حقيقي**، فلا يُعتبر جاهز للإنتاج قبل تنفيذ قائمة الاختبار في [testing-report-ar.md](testing-report-ar.md).

## 1. تقييم التوافق (باختصار)

| البند | النتيجة |
|---|---|
| المصدر الرسمي | قرأت توثيق EasyOrders من المستودع الرسمي `eazyorders/themes-docs` (آخر تحديث 17 يونيو 2026) وقالب البداية الرسمي داخل حزمة `easyorders@0.1.20` على npm. موقع التوثيق نفسه كان محجوب من شبكة بيئة العمل، لكن المحتوى هو نفس المصدر. |
| موقع المرجع mostawraad.com | **محجوب من شبكة بيئة العمل — لم أفحصه.** التصميم مبني على الوصف البصري في طلبك فقط. أي تشابه في تفاصيل دقيقة (خطوط، مسافات، صور) يحتاج مراجعة منك. |
| بنية الثيم | مطابقة لخريطة الملفات الرسمية: 20 سكشن ثابت + 13 سكشن رئيسية مخصصة + `style.css` + `script.js` + `schema.json` + `product-data-schema.json`. |
| السلة والدفع والطلبات | كلها من المنصة نفسها. الثيم بيكلمها فقط عن طريق الأحداث الموثقة (`quick-add`, `cart-click`, `toggle-wishlist`, `footer-subscribe`…). مفيش سلة موازية ولا مفاتيح API. |
| الجملة وبوكس الهدايا | متنفّذين بأقرب طريقة مدعومة — التفاصيل والحدود في [compatibility-ar.md](compatibility-ar.md). |

## 2. محتويات المجلد

```
easyorders-theme/
├── theme/                  ← ده الثيم (نفس شكل مجلد theme/ في الـ CLI)
│   ├── sections/           ← 20 ملف Liquid (هيدر، فوتر، صفحة المنتج، الأقسام…)
│   ├── home-sections/      ← 13 سكشن للصفحة الرئيسية (bp-*)
│   ├── style.css  script.js  schema.json  product-data-schema.json
│   ├── config.json         ← للمعاينة بالـ CLI فقط (مش بيترفع)
│   └── theme-data.json     ← للمعاينة بالـ CLI فقط (مش بيترفع)
├── dist/bazaar-pop-theme.zip  ← ملف الرفع الجاهز
├── tools/                  ← أدوات البناء والتحقق (لا تُرفع)
├── preview/                ← بيانات تجريبية واختبارات (لا تُرفع أبداً)
└── docs/                   ← التوثيق ده
```

> ملفات `sections/featured-products.liquid` وأخواتها (5 ملفات منتجات) و`home-sections/*/template.liquid` **مولّدة** من `tools/src-*` لأن المنصة مفيهاش `include`. لو هتعدّل كارت المنتج: عدّل `tools/partials/product-card.liquid` وشغّل `npm run build`.

## 3. التركيب

### أ) تجربة حية بدون نشر (مستحسن أولاً)
```bash
npm install -g easyorders
cd easyorders-theme
easyorders start          # هيسألك عن الـ subdomain ويفتح صفحة موافقة في لوحة التحكم
```
الـ CLI بيقرأ مجلد `theme/` ويعرض الثيم على متجرك عن طريق tunnel لجلستك أنت بس. لإنهاء المعاينة: أوقف السيرفر أو امسح كوكي `local_theme_src`.

### ب) الرفع للإنتاج
1. **قبل أي حاجة:** سجّل اسم الثيم الحالي المفعّل عندك، ونزّل نسخة منه لو اللوحة بتسمح (ده خط الرجوع).
2. من لوحة التحكم → الثيمات → الثيم المخصص → **رفع مجلد**، ارفع `dist/bazaar-pop-theme.zip` (أو مجلد `theme/` بعد حذف `config.json` و`theme-data.json`).
3. افتح **Home Builder** واضبط الإعدادات (القسم 4).
4. نفّذ قائمة الاختبار في [testing-report-ar.md](testing-report-ar.md) على المتجر قبل ما تفعّله للعملاء.

### ج) الرجوع (Rollback)
- من صفحة الثيمات فعّل الثيم القديم اللي سجلته في الخطوة 1. إعدادات `theme_data` بتاعة Bazaar Pop مش بتأثر على الثيمات التانية.
- لو عدّلت سكشن واحد من محرر الكود وحصلت مشكلة: ارفع الملف الأصلي من `theme/sections/` تاني.
- كل نسخة من الثيم موجودة في git — تقدر ترجع لأي commit وتبني الـ ZIP بـ `python3 tools/make-zip.py`.

> ملحوظة: أسماء القوائم في لوحة التحكم ممكن تختلف شوية عن الموصوف هنا؛ أنا مشفتش لوحة التحكم بنفسي.

## 4. الإعداد خطوة بخطوة

### 4.1 الألوان (Palette) — مهم
المنصة بترسم زرار "أضف للسلة" وفورم الطلب والسلة بنفسها وبتستخدم الـ Palette. عشان يبقوا بنفس روح الثيم، حط القيم دي في **Theme settings → Palette**:

| المفتاح | القيمة | المفتاح | القيمة |
|---|---|---|---|
| hd_bg | `#214BD9` | buy_btn_bg | `#FFDE00` |
| hd_text | `#FFFFFF` | buy_btn_text | `#0C1423` |
| ann_bg | `#0C1423` | buy_btn_border | `#0C1423` |
| ann_text | `#FFFFFF` | crt_btn_bg | `#214BD9` |
| ft_bg | `#0C1423` | crt_btn_text | `#FFFFFF` |
| ft_text | `#FFFFFF` | crt_btn_border | `#0C1423` |
| body_bg | `#FAF6EA` | product_sale_price_text | `#F2452E` |
| body_text | `#0C1423` | input_border | `#0C1423` |
| checkout_form_bg | `#FFFFFF` | checkout_heading_text | `#0C1423` |

ألوان الهيدر/الفوتر/الإعلانات في الثيم بتيجي من إعدادات الثيم (`color_*`). لو عايز تتحكم فيها من الـ Palette بدلها فعّل "استخدم ألوان الـ Palette".

### 4.2 الهيدر والفوتر وشريط الإعلانات
- **Header links:** اختار الأقسام بالترتيب: سناكس، مشروبات، قهوة وشاي، عناية وتجميل، حيوانات أليفة، بقالة، البراندات (صفحة أو قسم). الأقسام الفرعية بتظهر كقائمة منسدلة.
- **روابط إضافية** (إعدادات الثيم → الهيدر): مثلاً "اعمل بوكسك" `/#gift-box` و"الجملة" `/#wholesale`.
- **التوصيل لـ:** اكتب مناطق التوصيل الحقيقية؛ لو فاضية بتختفي.
- **Announcement bar:** اختار `marquee` واكتب إعلاناتك (فيه زرار إيقاف للحركة، وبتقف تلقائياً مع "تقليل الحركة").
- **Footer:** اختار الأقسام وصفحات المساعدة (الاستبدال، الشحن، تواصل معنا)، روابط السوشيال، وصورة طرق الدفع اللي بتقبلها فعلاً.
- **التواصل:** رقم واتساب بالصيغة الدولية (`2010xxxxxxxx`). الهاتف/الإيميل/العنوان بيتسحبوا من بيانات المتجر.

### 4.3 العملة
المنصة بتبعت رمز العملة من إعدادات المتجر. لو عايزها تظهر "ج.م" اكتبها في "شكل العملة". الأرقام بتتنسق بفواصل الآلاف تلقائياً.

### 4.4 ترتيب الصفحة الرئيسية (مطابق لتسلسل المرجع)

| # | الجزء | السكشن في Home Builder |
|---|---|---|
| A | شريط الإعلانات | من إعدادات Announcement (داخل الهيدر) |
| B–C | الهيدر الأزرق + شريط الأقسام | تلقائي (header) |
| D | شريط الدول | **Bazaar Pop: شريط الدول** |
| E | الهيرو | **Bazaar Pop: الهيرو الرئيسي** (أو `Slider` لو بتفضل بانرات) |
| — | الأقسام الدائرية | `Categories` (اختياري) |
| F | تسوق حسب المزاج | **Bazaar Pop: تسوّق حسب المزاج** |
| G | العناية والجمال | **Bazaar Pop: قسم مميز** |
| H | بانر دعائي | **Bazaar Pop: بانر دعائي** |
| — | الأكثر مبيعاً | `List products` / `Featured products` (منتجات قسم) |
| I | الجملة | **Bazaar Pop: الجملة / الكراتين** (معرّف `wholesale`) |
| J | بوكس الهدايا | **Bazaar Pop: اعمل بوكسك (دعاية)** + **بنّاء بوكس الهدايا** (معرّف `gift-box`) |
| K | وصول قريب | **Bazaar Pop: عدّ تنازلي** |
| L | بوكسات جاهزة | **Bazaar Pop: شريط منتجات** (شكل الكارت = بوكس ملوّن) |
| M | الحيوانات الأليفة | **Bazaar Pop: منتجات بتبويبات** |
| N | اتفرج واشتري | **Bazaar Pop: اتفرج واشتري** |
| O | النشرة | **Bazaar Pop: الاشتراك في النشرة** |
| P | الفوتر | تلقائي (footer) |

**قاعدة عامة:** أي سكشن ناقص محتواه الأساسي (مفيش عنوان، أو مفيش منتجات/عناصر) **بيختفي بالكامل** بدل ما يظهر مكسور. لو أضفت سكشن ومظهرش، كمّل بياناته.

### 4.5 الروابط داخل السكشنات
كل زرار له "نوع الرابط": قسم / منتج / صفحة / رابط مكتوب. القسم/المنتج/الصفحة بيتحولوا لرابط حقيقي بعد التحميل (عن طريق API الكتالوج العام). الرابط المكتوب (`/collections/...` أو `/#gift-box`) بيشتغل حتى بدون جافاسكربت — استخدمه للأزرار المهمة.

### 4.6 بيانات المنتج الإضافية
في صفحة تعديل المنتج هيظهر "Theme data": البراند، بلد المنشأ + العلم، الوزن، SKU، الصلاحية، ستيكر مخصص، وتبويبات إضافية. **كل حقل بيظهر فقط لو اتكتب.** اكتب الصلاحية بدقة لكل دفعة أو سيبها فاضية.

### 4.7 العدّ التنازلي
اكتب ميعاد حقيقي `YYYY-MM-DD HH:mm` واختار المنطقة الزمنية (القاهرة افتراضياً — بيحسب التوقيت الصيفي تلقائياً). بعد الانتهاء: يا رسالة يا إخفاء السكشن. اكتب كمان "الميعاد بالكلام" عشان يظهر حتى لو الجافاسكربت متعطل.

### 4.8 الإنجليزي
الثيم بيقرا لغة الصفحة (`lang`) — المتغير ده مستخدم في القالب الرسمي لكن مش موثق، **فلازم يتجرب**. نصوص المنصة (أضف، تسوق الآن…) بتترجم تلقائياً. للنصوص اللي بتكتبها أنت فيه حقول `_en` اختيارية؛ لو فاضية بيظهر العربي. تفعيل الإنجليزي محتاج إضافة Multi-language من المنصة (زرار اللغة بيختفي من غير الإضافة).

## 5. ممنوعات مقصودة في الثيم
- مفيش عداد زوار وهمي، ولا عداد تنازلي بيتعاد لكل زائر، ولا "باقي 3 قطع" مخترعة (سكشنات fake-* فاضية؛ نص المخزون يظهر فقط لو فعّلته وكتبته بنفسك).
- مفيش "تم الاشتراك بنجاح" أو "تم الطلب" من الثيم — التأكيد من المنصة فقط.
- مفيش شارة "مشتري موثّق" على التقييمات.
- كل الأرقام والوعود (توصيل، خصومات، جملة) بتكتبها أنت.

## 6. للمطوّر
```bash
npm install --no-save liquidjs@10   # مرة واحدة
npm run build      # يولّد config.json للسكشنات + السكشنات من tools/src-*
npm run validate   # تحقق من Liquid والـ schemas وخطافات المنصة
node preview/render.mjs && node preview/test.mjs   # معاينة واختبارات متصفح
npm run zip        # dist/bazaar-pop-theme.zip
```

ملحوظة أمان: قالب البداية داخل حزمة `easyorders` الرسمية على npm (0.1.20) فيه ملف `.cli-tokens.json` لمتجر المطوّر. ملف `.gitignore` هنا بيستبعده؛ ما ترفعش ملف زيه لأي مستودع.
